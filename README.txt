ESHAl'S BIRTHDAY ADVENTURE - COMPLETE FOLDER

DO NOT rename or move files inside this folder.

CONTENTS
- index.html              Main website/game page
- css/style.css           Pastel pink website styling
- js/game.js              Complete game logic, graphics, physics, hearts, ending
- audio/cute_pink_theme.wav  Original looping background music
- images/                 Reserved for later custom character/art assets
- README.txt              This file

PLAY LOCALLY
1. Open index.html in Chrome/Edge.
2. Click PLAY.
3. Controls:
   A or Left Arrow = move left
   D or Right Arrow = move right
   W / Up Arrow / Space = jump
   S or Down Arrow = crouch/drop

PUT IT ONLINE WITH GITHUB PAGES
1. Go to github.com and create a new PUBLIC repository, for example:
   eshals-birthday-game
2. Open the COMPLETE folder on your computer.
3. Drag ALL contents into the GitHub upload screen:
   index.html
   css folder
   js folder
   audio folder
   images folder (GitHub may ignore an empty folder; that is okay)
   README.txt
4. Commit/upload the files.
5. In the repository open Settings > Pages.
6. Source: Deploy from a branch.
7. Branch: main.
8. Folder: /(root).
9. Save.
10. Wait for GitHub Pages to publish it.
11. Open the Pages URL. Eshal only needs that URL to play.

IMPORTANT
index.html must remain at the ROOT of the repository.
css/style.css, js/game.js, and audio/cute_pink_theme.wav must keep those exact paths.
